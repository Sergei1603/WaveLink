# public/

Статические файлы, которые Vite отдаёт из корня сайта.

## Фоновые изображения

Оболочка и экраны входа рисуют фотографический фон поверх CSS-градиента.
Сами файлы в репозиторий не закоммичены — положите их сюда:

| Файл | Где используется | Как обрабатывается |
| --- | --- | --- |
| `backdrop.*` | оболочка приложения (за всеми страницами) | `saturate(.3) brightness(.5)`, `mix-blend-mode: lighten`, позиция `58% 42%` |
| `backdrop-auth.*` | страницы «Вход» и «Регистрация» | `saturate(.4) brightness(.82)`, `mix-blend-mode: lighten`, позиция `62% 50%` |

Расширение любое из `png`, `jpg`, `jpeg`, `webp` — `Backdrop.tsx` перебирает
их по очереди. Если ни один файл не найден, остаётся только градиент, и это
рабочее состояние: ошибок в консоли не будет, вёрстка не поедет.

Рекомендуемый размер — от 1920px по ширине; изображение растягивается
`object-fit: cover` на всю площадь.
